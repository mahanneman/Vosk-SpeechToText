## پنل شناور

- آیکون شناور کوچک با اندازه تقریبی ۵۸×۵۸ پیکسل و همیشه در بالاترین لایه پنجره‌ها.
- یک کلیک، پنل دسترسی سریع را باز می‌کند؛ دوبارکلیک، پنجره اصلی را نمایش می‌دهد.
- پنل کشویی پس از بازشدن حدود ۲۶۸×۱۱۸ پیکسل است و کنترل‌های شروع/توقف، ابزار متن و پنجره کامل را دارد.
- بازشدن خودکار با عبور موس وجود ندارد.
- جابه‌جایی فقط از دستگیره بالای پنل انجام می‌شود؛ کلیک روی دکمه‌ها باعث Drag نمی‌شود.
- آستانه حرکت موس از مقدار استاندارد Qt پیروی می‌کند تا کلیک ناخواسته هنگام جابه‌جایی رخ ندهد.
- موقعیت آیکون با QSettings ذخیره می‌شود.

## اصلاح‌های فنی مهم

- دریافت وضعیت اینترنت به Thread پس‌زمینه منتقل شد تا راه‌اندازی رابط کاربری منتظر شبکه نماند.
- صف داده صوتی محدود شد؛ در فشار پردازشی، قدیمی‌ترین بلوک کنار گذاشته می‌شود تا تأخیر بی‌نهایت رشد نکند.
- نتیجه میانی Vosk برای نمایش زنده اضافه شد؛ متن میانی مستقیماً تایپ نمی‌شود تا متن تکراری تولید نشود.
- هنگام توقف، بلوک‌های صوتی صف‌شده پردازش و نتیجه نهایی Vosk تخلیه می‌شود.
- توقف/بستن جریان صدا در Thread مالک جریان انجام می‌شود تا رقابت بین Thread رابط و Thread صدا کاهش یابد.
- شروع ضبط مجدد تا پایان بسته‌شدن نشست قبلی محافظت می‌شود.
- فرمان‌های صوتی با تطبیق عبارت کامل اجرا می‌شوند، نه تطبیق زیررشته؛ بنابراین کلمه‌ای مانند copy داخل جمله عادی به‌تنهایی فرمان محسوب نمی‌شود.
- فرمان‌های فارسی رایج برای کپی، چسباندن، پاک‌کردن، خط جدید، واگرد و توقف ضبط اضافه شدند.
- متن‌های تشخیص‌داده‌شده در حافظه نشست نگه‌داری می‌شوند؛ پنل متن ۲۰۰ قطعه آخر را باز می‌کند و سقف حافظه تاریخچه ۱۰۰۰ قطعه است.
- آرشیو ZIP مدل‌ها در برابر مسیرهای مطلق، مسیرگردی و پیوند نمادین بررسی می‌شود.
- مدل جدید ابتدا در پوشه موقت استخراج و اعتبارسنجی می‌شود؛ مدل موجود فقط پس از آماده‌شدن جایگزین می‌شود و در صورت شکست جایگزینی، نسخه قبلی بازیابی می‌شود.
- مدل کمکی speaker-ID به‌عنوان زبان مستقل تشخیص گفتار عرضه نمی‌شود.
- خطا یا توقف غیرمنتظره ضبط، وضعیت تایمر و آیکون شناور را همگام می‌کند.

## محدودیت‌های آگاهانه

- زبان قابل تشخیص به مدل Vosk نصب‌شده بستگی دارد؛ وجود ۵۶ ابزار عمومی به معنی پشتیبانی تشخیص گفتار از همه زبان‌های جهان نیست.
- ابزارهای متن آفلاین هستند و خروجی مدل گفتار را ویرایش می‌کنند؛ جایگزین مدل زبانی، ترجمه ماشینی یا تصحیح معنایی هوشمند نیستند.
- شمارش و فراوانی واژه‌ها بر مبنای فاصله و جداکننده‌های متنی است؛ برای زبان‌هایی مانند چینی و تایلندی که مرزبندی واژه با فاصله انجام نمی‌شود، شمارش زبانی دقیق محسوب نمی‌شود.
- برخی ابزارهای حروف بزرگ/کوچک فقط روی خط‌هایی اثر دارند که تمایز بزرگ و کوچک دارند.
- اصلاح محاوره‌ای فارسی و اصلاح املای رایج قاعده‌محور است؛ برای متن‌های حقوقی، پزشکی یا تخصصی، نتیجه باید بازبینی شود.
- این محیط اجرای برنامه، بسته‌های PyQt5، Vosk، sounddevice و keyboard را ندارد؛ بنابراین کامپایل نحوی و تست مستقل موتور ابزارها انجام شده، اما اجرای کامل GUI و آزمون واقعی میکروفون در این محیط ممکن نبود.

## بررسی انجام‌شده

- `python -m py_compile` و `compileall` بدون خطای نحوی اجرا شدند.
- تعداد ابزارهای عمومی: ۵۶.
- تعداد ابزارهای فارسی: ۳۰.
- تست مستقل توابع تمام ۸۶ ابزار با ورودی نمونه اجرا شد؛ خطای اجرایی مشاهده نشد.
- اجرای واقعی PyQt، دسترسی میکروفون، hotkey سراسری و دانلود مدل نیازمند نصب وابستگی‌ها و آزمون روی سیستم مقصد است.

## نصب وابستگی‌ها

```bash
python -m pip install PyQt5 vosk sounddevice keyboard requests
```

## اجرا

```bash
python Vosk_SpeechToText_v3.py
```
