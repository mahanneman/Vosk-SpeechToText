# 🎤 برنامه تشخیص گفتار شناور (Vosk + PyQt5)

برنامه شناور تشخیص گفتار **آفلاین** با پشتیبانی از زبان‌های **فارسی** و **انگلیسی**.

با استفاده از مدل‌های Vosk کار می‌کند و متن تشخیص‌داده‌شده را مستقیماً تایپ می‌کند.

---

## ✨ امکانات

- تشخیص گفتار کاملاً آفلاین (بدون نیاز به اینترنت)
- پشتیبانی از زبان‌های فارسی و انگلیسی
- پنجره شناور و همیشه در بالای سایر پنجره‌ها
- شورت‌کات تغییر زبان: `Ctrl + Shift + L`
- دستورات صوتی برای تغییر زبان
- تایمر برای روشن/خاموش کردن خودکار ضبط
- دستورات صوتی کمکی:
  - `copy` / `ctrl c`
  - `paste` / `ctrl v`
  - `delete all` / `clear`
  - `enter` / `new line`
  - `undo` / `ctrl z`
- پشتیبانی از System Tray
- قابلیت کشیدن پنجره با ماوس
