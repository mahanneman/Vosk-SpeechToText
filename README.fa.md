# 🎤 Vosk Voice Typing – تبدیل گفتار به متن با Vosk

**نسخه ۳** · برنامه‌ی تبدیل گفتار به متن با قابلیت تایپ خودکار، پشتیبانی از چندین زبان، رابط کاربری شناور، تایمر هوشمند و مدیریت ساده‌ی مدل‌ها.

## ✨ ویژگی‌های نسخه ۳

- ✅ **تشخیص گفتار بلادرنگ** با استفاده از موتور Vosk – بدون نیاز به اینترنت
- 🌍 **پشتیبانی از بیش از ۲۰ زبان** (فارسی، انگلیسی، روسی، آلمانی، فرانسوی، اسپانیایی، ایتالیایی، چینی، و...)
- 🖥️ **پنجره‌ی شناور** با قابلیت جا‌به‌جایی و همیشه در بالا
- ⏱️ **تایمر هوشمند** برای شروع یا توقف خودکار ضبط (حالت‌های خاموش/روشن)
- ⌨️ **کلیدهای میانبر جهانی** (بدون نیاز به فوکوس برنامه):
  - `Ctrl+Shift+S` → شروع ضبط
  - `Ctrl+Shift+X` → توقف ضبط
  - `Ctrl+Shift+L` → تغییر زبان تشخیص
- 🗣️ **دستورات صوتی** (بدون نیاز به موس/صفحه‌کلید):
  - "copy" / "paste" / "enter" / "delete all" / "undo"
  - تغییر زبان با گفتن "تغییر انگلیسی" یا "persian"
- 📥 **مدیریت مدل‌های زبان** (دانلود خودکار از سرور Vosk، افزودن مدل محلی، حذف مدل)
- 🌐 **رابط کاربری دوزبانه** (فارسی و انگلیسی) با قابلیت تغییر لحظه‌ای
- 🔔 **آیکون سینی سیستم** (System Tray) برای اجرا در پس‌زمینه
- 🎨 **رابط کاربری مدرن و نیمه‌شفاف** با تم تیره

## 🚀 نصب و راه‌اندازی

### پیش‌نیازها
- **Python 3.7 یا بالاتر**
- **کتابخانه‌های مورد نیاز** (در `requirements.txt` آمده است)

### مراحل نصب

#### ۱. دریافت کد
```bash
git clone https://github.com/mahanneman/vosk-voice-typing.git
cd vosk-voice-typing
۲. نصب وابستگی‌ها
bash
pip install -r requirements.txt
توجه برای لینوکس: ممکن است نیاز به نصب portaudio و libportaudio2 داشته باشید:

bash
sudo apt install portaudio19-dev python3-pyaudio
۳. اجرای برنامه
bash
python Vosk_SpeechToText_v3.py
🧭 راهنمای استفاده
🔹 بار اول اجرا
برنامه ابتدا مدل‌های موجود را بررسی می‌کند.

اگر هیچ مدلی یافت نشد، پیام "هیچ مدلی یافت نشد" نشان داده می‌شود.

برای دانلود مدل، روی دکمه‌ی "📥 مدیریت مدل‌ها" کلیک کنید.

🔹 مدیریت مدل‌ها
در پنجره‌ی مدیریت، می‌توانید:

مدل‌های موجود را از لیست انتخاب و دانلود کنید (نیاز به اینترنت).

مدل محلی خود را با انتخاب پوشه و وارد کردن کد زبان (مثلاً fa) اضافه کنید.

مدل‌های ناخواسته را حذف کنید (فقط مدل‌های داخل پوشه‌ی models قابل حذف هستند).

پس از دانلود یا افزودن مدل، زبان مورد نظر را از کادر انتخاب بالا انتخاب کنید.

🔹 شروع ضبط
روی دکمه‌ی "🎤 شروع" کلیک کنید یا کلید ترکیبی Ctrl+Shift+S را بزنید.

متن تشخیص‌داده‌شده به‌طور خودکار در هر برنامه‌ای که فوکوس داشته باشد تایپ می‌شود.

در صورت عدم امکان تایپ (مثلاً در محیط‌های خاص)، متن در کلیپ‌بورد کپی می‌شود.

🔹 توقف ضبط
دکمه‌ی "⏹ توقف" یا کلید Ctrl+Shift+X.

🔹 تغییر زبان
از کادر انتخاب زبان یا کلید Ctrl+Shift+L استفاده کنید.

همچنین می‌توانید با گفتن "تغییر انگلیسی" یا "persian" (در حالت انگلیسی) زبان را عوض کنید.

🔹 تایمر هوشمند
با دکمه‌های + و − زمان مورد نظر را تنظیم کنید (حداکثر ۹۹:۵۹).

حالت خاموش‌کن: پس از اتمام تایمر، ضبط متوقف می‌شود.

حالت روشن‌کن: پس از اتمام تایمر، ضبط شروع می‌شود.

تایمر در پس‌زمینه کار می‌کند و در نوار وضعیت نمایش داده می‌شود.

🔹 دستورات صوتی
در حین ضبط، اگر یکی از عبارات زیر را بگویید، دستور مربوطه اجرا می‌شود:

"copy" → کپی متن انتخاب‌شده

"paste" → چسباندن

"enter" / "new line" → کلید Enter

"delete all" / "clear" → پاک کردن کل متن

"undo" / "ctrl z" → خنثی‌سازی

تغییر زبان (فارسی/انگلیسی) با گفتن "تغییر انگلیسی" یا "persian"

⌨️ کلیدهای میانبر جهانی
کلید ترکیبی	عملکرد
Ctrl+Shift+S	شروع ضبط
Ctrl+Shift+X	توقف ضبط
Ctrl+Shift+L	تغییر زبان تشخیص (چرخه‌ای)
این کلیدها در تمام سیستم‌عامل‌ها کار می‌کنند و نیازی به فوکوس روی پنجره‌ی برنامه ندارند.

📦 ساخت فایل اجرایی (اختیاری)
برای ساخت فایل .exe (ویندوز) یا اجرایی در سایر سیستم‌ها می‌توانید از PyInstaller استفاده کنید:

bash
pip install pyinstaller
pyinstaller --onefile --windowed --icon=icon.ico Vosk_SpeechToText_v3.py
فایل icon.ico را می‌توانید از تصویر میکروفون موجود در کد بسازید یا از یک فایل جداگانه استفاده کنید.

🐧 نکات مخصوص لینوکس
برای دسترسی به میکروفون، مطمئن شوید کاربر شما در گروه audio قرار دارد:

bash
sudo usermod -a -G audio $USER
در برخی توزیع‌ها ممکن است نیاز به نصب python3-pyqt5 و python3-pyqt5.qtsvg داشته باشید.

اگر صدا ضبط نمی‌شود، ورودی پیش‌فرض را در تنظیمات سیستم بررسی کنید یا از pavucontrol استفاده کنید.
