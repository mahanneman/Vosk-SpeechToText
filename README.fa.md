# 🎤 تایپ صوتی Vosk – کیبورد تبدیل گفتار به متن و فضای کار پژوهشی
**نسخه ۵.۰ حرفه‌ای (Version 5.0 Pro)** · تشخیص گفتار بلادرنگ که مستقیماً در هر برنامه‌ای تایپ می‌کند، در وب جستجو می‌کند و جزوه‌های درسی و پژوهشی ساختاریافته می‌سازد.

کاملاً آفلاین کار می‌کند، از بیش از ۲۰ زبان پشتیبانی می‌کند، با داک شناور PiP روی تمام پنجره‌ها قرار می‌گیرد و دارای تایمر هوشمند، فرمان‌های صوتی، ماکروهای سفارشی، فضای جزوه‌برداری شبیه Notion/EndNote و مدیریت مدل داخلی است.

---

## ✨ ویژگی‌ها
- ✅ **تشخیص گفتار بلادرنگ با موتور Vosk** – پس از دریافت مدل نیازی به اینترنت نیست
- 🌍 **پشتیبانی از ۲۰+ زبان** (فارسی، انگلیسی، روسی، آلمانی، فرانسوی، اسپانیایی، ایتالیایی، چینی، عربی، ترکی و ...)
- 🖥️ **پنجره شناور و داک PiP** – همیشه در رو، قابل جابه‌جایی، نیمه‌شفاف، با نشانگر زبان فعال (`FA` / `EN`) و کنترل با تک‌کلیک و دابل‌کلیک
- 📓 **فضای کار جزوه‌برداری و پژوهش (سبک Notion + EndNote)** – دسته‌بندی بر اساس مباحث/فصل‌ها، ثبت بلوک‌های یادداشت، تیتر بخش، نقل‌قول/نکته کلیدی، منبع/رفرنس و اقدام/کار پژوهشی همراه با تگ و منبع، جستجوی زنده و خروجی **Markdown (`.md`)** و **BibTeX (`.bib`)**
- 🔎 **سرچ صوتی و نشانه‌گذاری** – جستجوی مستقیم در مرورگر (`جستجو کن ...` / `سرچ کن ...`) و درج نشانه‌گذاری و بلوک (`نقطه`، `ویرگول`، `علامت سوال`، `خط جدید`، `پاراگراف بعد`، `بولت`)
- ⚙️ **ماکروهای صوتی سفارشی (`macros.json`)** – اجرای خودکار کلید میانبر (`hotkey`)، لینک (`url`)، دستور سیستم (`command`) یا متن (`text`) با صدا
- ⏱️ **تایمر هوشمند** – شروع یا توقف خودکار ضبط پس از پایان شمارش معکوس (در دو حالت `خاموش‌کن` و `روشن‌کن`)
- ⌨️ **کلیدهای میانبر سراسری** (حتی زمانی که برنامه در فوکوس نیست):
  - `Ctrl+Shift+S` ← شروع ضبط
  - `Ctrl+Shift+X` ← توقف ضبط
  - `Ctrl+Shift+L` ← تغییر زبان تشخیص (چرخشی)
- 🗣️ **فرمان‌های صوتی** – کنترل بدون نیاز به کیبورد (`کپی`، `پیست`، `اینتر`، `پاک کن`، `انجام شد`، `یادداشت کن ...`، `مبحث جدید ...`، `منبع ...`، `نکته مهم ...` و تغییر زبان)
- 📥 **مدیریت مدل داخلی** – دانلود مدل از سرور Vosk، افزودن مدل محلی و حذف مدل‌های غیرضروری
- 🌐 **رابط کاربری کاملاً دو زبانه (فارسی / انگلیسی)** – تغییر لحظه‌ای زبان و جهت چیدمان (`RTL` / `LTR`) در تمام پنجره‌ها و دیالوگ‌ها
- 🔔 **آیکون سینی سیستم (System Tray)** – اجرا در پس‌زمینه
- 🎨 **تم تیره مدرن** با گوشه‌های گرد و شفافیت کنترل‌شده

## 🚀 نصب و راه‌اندازی

### پیش‌نیازها
- پایتون ۳.۷ یا بالاتر
- کتابخانه‌های پایتون: `vosk`، `PyQt5`، `sounddevice`، `keyboard`، `requests`

### مراحل نصب
1. **دریافت مخزن**
   ```bash
   git clone https://github.com/mahanneman/vosk-voice-typing.git
   cd vosk-voice-typing
   ```

2. **نصب وابستگی‌ها**
   ```bash
   pip install vosk PyQt5 sounddevice keyboard requests
   ```
   **کاربران لینوکس:** ممکن است ابتدا نیاز به نصب PortAudio داشته باشید:
   ```bash
   sudo apt install portaudio19-dev python3-pyaudio
   ```

3. **اجرای برنامه**
   ```bash
   python vosk_stt_pro.py
   ```

## 🧭 نحوه استفاده

### اولین اجرا
برنامه پوشه `models/` و پوشه پروژه را برای یافتن مدل‌های نصب‌شده بررسی می‌کند.
اگر مدلی پیدا نشود، پیام `"هیچ مدلی یافت نشد. لطفاً مدل دانلود کنید."` نمایش داده می‌شود.
روی دکمه **"📥 مدیریت مدل‌ها"** کلیک کنید تا پنجره مدیریت مدل باز شود.

### مدیریت مدل‌ها
در بخش مدیریت مدل‌ها می‌توانید:
- مدل‌های رسمی Vosk را از فهرست دانلود کنید (نیاز به اینترنت دارد).
- یک مدل محلی را با انتخاب پوشه آن (حاوی `am/final.mdl`) و وارد کردن کد زبان (مثلاً `fa` برای فارسی یا `en` برای انگلیسی) اضافه کنید.
- مدل‌های اضافی را حذف کنید (فقط مدل‌های داخل پوشه `models/` قابل حذف هستند).

پس از افزودن مدل، آن را از منوی کشویی زبان تشخیص در پنجره اصلی انتخاب کنید.

### شروع ضبط
روی دکمه **"🎤 شروع"** کلیک کنید یا کلیدهای `Ctrl+Shift+S` را بفشارید (یا روی آیکون شناور PiP دابل‌کلیک کنید).
در صورت فعال بودن **تایپ خودکار**، متن تشخیص‌داده‌شده مستقیماً در پنجره یا کادر فعال تایپ می‌شود.
اگر **تایپ خودکار** خاموش باشد یا در محیطی محدود تایپ انجام نشود، متن در کلیپ‌بورد کپی می‌شود.

### توقف ضبط
روی **"⏹ توقف"** کلیک کنید یا کلیدهای `Ctrl+Shift+X` را بفشارید (یا روی آیکون شناور PiP دابل‌کلیک کنید).

### تغییر زبان
از منوی کشویی زبان تشخیص در پنجره اصلی استفاده کنید، با `Ctrl+Shift+L` بین زبان‌های نصب‌شده جابه‌جا شوید، یا با تغییر **زبان برنامه**، متن‌ها و چیدمان پنجره‌ها را بین فارسی و انگلیسی تغییر دهید.
همچنین می‌توانید با صدا زبان تشخیص را عوض کنید: در حالت فارسی بگویید `"انگلیسی کن"` یا `"برو انگلیسی"` و در حالت انگلیسی بگویید `"persian"` یا `"farsi"`.

### فضای کار جزوه‌برداری و پژوهش (سبک Notion + EndNote)
روی **"📓 جزوه و پژوهش"** کلیک کنید تا پنجره فضای کار باز شود:
- در بخش مباحث (`notes/research_notebooks.json`) مبحث جدید بسازید یا تغییر دهید، یا با صدا بگویید `"مبحث جدید <نام>"` / `"topic <name>"`.
- بلوک‌های مختلف را با فرم یا فرمان صوتی ثبت کنید:
  - `"یادداشت کن <متن>"` / `"note <text>"` ← یادداشت
  - `"منبع <رفرنس>"` / `"citation <ref>"` ← منبع / ارجاع
  - `"نکته مهم <متن>"` / `"quote <text>"` ← نقل‌قول / نکته کلیدی
- در یادداشت‌ها، تگ‌ها و منابع جستجو کنید، متن را کپی کنید یا به فرمت **Markdown (`.md`)** و **BibTeX (`.bib`)** خروجی بگیرید.

### تایمر هوشمند
با دکمه‌های `+` و `−` زمان شمارش معکوس را تنظیم کنید:
- حالت **خاموش‌کن** – با اتمام زمان تایمر، ضبط متوقف می‌شود.
- حالت **روشن‌کن** – با اتمام زمان تایمر، ضبط شروع می‌شود.

تایمر در پس‌زمینه کار می‌کند و وضعیت آن در نوار وضعیت نمایش داده می‌شود.

### فرمان‌های صوتی
هنگام ضبط، با گفتن عبارت‌های زیر اکشن مربوطه اجرا می‌شود:

| فرمان صوتی | عملکرد |
| :--- | :--- |
| `کپی` / `copy` | کپی کردن متن انتخاب‌شده |
| `پیست` / `بچسبان` / `paste` | چسباندن از کلیپ‌بورد |
| `اینتر` / `enter` / `new line` | زدن کلید Enter |
| `پاک کن` / `حذف همه` / `delete all` | پاک کردن کل متن فیلد فعال |
| `انجام شد` / `برگردون` / `undo` | بازگرداندن آخرین عمل (Undo) |
| `جستجو کن ...` / `سرچ کن ...` | جستجوی عبارت در مرورگر |
| `یادداشت کن ...` / `مبحث جدید ...` / `منبع ...` / `نکته مهم ...` | ثبت یادداشت، ساخت مبحث، ثبت منبع یا نقل‌قول |
| `نقطه` / `ویرگول` / `خط جدید` / `پاراگراف بعد` / `بولت` | درج نشانه‌گذاری یا ساختار بلوک |
| `انگلیسی کن` / `برو انگلیسی` (در فارسی) | تغییر زبان تشخیص به انگلیسی |

## 🐧 نکات ویژه لینوکس
برای دسترسی به میکروفون، مطمئن شوید کاربر شما عضو گروه `audio` است:
```bash
sudo usermod -a -G audio $USER
```
در برخی توزیع‌ها ممکن است نیاز به بسته‌های زیر باشد:
```bash
sudo apt install python3-pyqt5 python3-pyqt5.qtsvg
```
اگر صدا دریافت نشد، ورودی پیش‌فرض را در تنظیمات سیستم یا با `pavucontrol` بررسی کنید.
